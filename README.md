# 3SA Dialer – landing page

Statisk landing page til 3sadialer.io. Ren HTML/CSS/JS uden build-step.

- `index.html` – hele siden (header, indhold, footer)
- `logo.png` – logo (bruges i header, footer og preloader)
- `netlify.toml` – hosting-opsætning

Ændringer pushes til `main` og udgives automatisk.
